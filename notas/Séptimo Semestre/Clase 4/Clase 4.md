GitFlow está configurado. Resumen de lo realizado:
- main → rama de producción (actualizada con último commit)
- develop → rama de desarrollo (creada desde main)
- Ambas ramas están en GitHub: https://github.com/josuel-munendez/Proyecto1_springsena
Para trabajar con GitFlow:
git checkout develop                          # trabajar en develop
git checkout -b feature/nueva-funcionalidad   # crear feature
# ... hacer cambios ...
git checkout develop && git merge feature/nueva-funcionalidad
git push origin develop
